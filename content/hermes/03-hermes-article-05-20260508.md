## 痛点钩子

大多数人用Hermes Agent的方式，和用普通聊天机器人没有区别——问一个问题，得到一个答案，关掉对话。但社区里有一批深度用户，他们用Hermes做的事情看起来像是完全不同的工具：**自动生成周报、管理5个并行项目的上下文、把通勤语音变成可执行的行动项**。差距不在于谁更聪明，而在于是否发现了这些隐藏用法。

## 隐藏用法一：自动生成周报（告别"这周忙了啥"）

周五下午最头疼的问题：这周到底做了什么？

在Hermes中发送：
```
帮我生成本周工作周报，重点突出[项目名称]的进展。
```

Hermes会基于过去7天的对话记录，自动提取：
- 每个项目的关键决策和进展
- 遇到的问题和解决方案
- 下周的待办事项

**进阶技巧**：用户可以设置每周五18:00的Nudge提醒，让Hermes主动推送周报草稿，确认后即可发送。

## 隐藏用法二：跨项目上下文管理（多项目党的福音）

同时维护多个技术方向时，最大的痛点是每个项目都要重新解释背景。Hermes的上下文标签功能解决了这个问题：

```bash
# 为不同项目设置上下文
/hermes context set "ai-tools-review" --from-history 7d
/hermes context set "hermes-agent-dev" --files ./src/**/*.py
/hermes context set "knowledge-management" --from-memories 30d
```

切换项目时，只需 `/hermes context switch ai-tools-review`，Hermes立刻进入该项目的完整思维模式——包括历史决策、代码风格偏好、未解决的问题。

**实际效果**：从"AI工具评测"项目切换到"知识管理"项目时，Hermes会自动调取相关的阅读笔记和讨论记录，无需任何手动粘贴。

## 隐藏用法三：语音备忘录的智能转写（通勤时间的价值翻倍）

通勤时的语音想法，传统流程是：录音→手动转写→整理分类→提取行动项。整个过程至少30分钟。

Hermes的处理流程：
1. **精准转写**：识别语音中的技术术语（准确率95%+），自动纠正同音词
2. **智能分类**：自动归类到不同主题（AI工具、编程技巧、生活感悟、项目想法）
3. **行动项提取**：生成可执行的下一步操作（"提到要测试Claude Code的新功能，是否需要准备测试案例？"）

**关键优势**：语音内容不仅被记录，还会与已有知识库进行语义关联。用户三周前随口提到的一个想法，可能在今天讨论相关话题时被主动召回。

## 隐藏用法四：知识图谱可视化（看见知识成长轨迹）

由社区开发的knowledge-graph-visualizer技能，安装后运行：

```bash
hermes skill install knowledge-graph-visualizer
/kg generate --from-memories 30d --output html
```

生成的HTML文件直观展示过去30天的知识网络：
- **节点大小**：代表该主题被讨论的频率
- **连线粗细**：代表主题之间的关联强度
- **颜色深浅**：代表最近活跃程度

**实际用途**：
- 发现知识结构中的盲区（某个重要领域几乎没有节点）
- 识别过度集中的领域（某个节点过大，说明时间分配失衡）
- 追踪知识成长轨迹（对比不同时间段的图谱变化）

## 隐藏用法五：智能提醒与习惯养成（比任何APP都懂你）

普通的提醒工具只知道"在什么时间提醒什么"。Hermes的提醒系统知道"为什么提醒"和"提醒时应该附带什么素材"。

配置示例：
```
每周日晚上，提醒回顾本周的阅读笔记，并基于笔记内容生成下周的学习计划。
```

执行时，Hermes不仅准时提醒，还会：
1. 调取本周所有标记过的阅读笔记
2. 分析笔记中的高频主题和知识空白
3. 生成结构化的下周学习计划，附带推荐资源
4. 对比上周计划完成率，给出调整建议

## 记忆锚点

**反常识结论**：Hermes Agent的"隐藏技能"之所以隐藏，不是因为功能难找，而是因为大多数人从未认真配置过记忆系统。所有隐藏用法的底层依赖都是**持久化记忆**——没有记忆积累，周报生成没有数据来源，上下文管理没有历史素材，知识图谱没有节点可画。**记忆系统是1，隐藏技能是后面的0。**
