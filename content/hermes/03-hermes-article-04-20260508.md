## 痛点钩子

新工具刚上手时总是充满希望：功能强大、设计优雅、社区活跃。但三天后，大多数人都会遇到同一个问题——**配置复杂、平台切换混乱、记忆功能没有真正用起来**。不是工具不好，而是缺少一个清晰的操作路径：从"装上"到"真正用起来"，中间到底需要几步？

## 三步上手路径：从安装到产生实际价值

### 第一步：核心组件安装（5分钟）

Hermes Agent采用单一网关架构，所有平台通过同一个网关接入。安装只需两步：

```bash
# 安装网关（需要Node.js 22+）
npm install -g @nous/hermes-gateway

# 启动网关
hermes gateway start
```

启动后，网关会在本地运行，负责管理所有平台的消息路由和记忆存储。

### 第二步：平台接入与优先级选择

并非所有平台都需要一次性接入。根据使用场景，按优先级选择接入顺序：

| 优先级 | 平台 | 配置难度 | 推荐场景 |
|--------|------|----------|---------|
| P0 | Telegram | ⭐ 简单 | 移动端快速记录、语音备忘录 |
| P1 | Slack | ⭐⭐ 中等 | 办公场景、团队协作 |
| P2 | Discord | ⭐⭐ 中等 | 技术讨论、社区交流 |
| P3 | CLI | ⭐⭐⭐ 稍复杂 | 开发调试、代码辅助 |
| P3 | WhatsApp/Signal | ⭐⭐ 中等 | 个人日常使用 |

**建议**：先接入Telegram验证记忆功能，确认预期后再逐步扩展其他平台。

### 第三步：初始化记忆（关键步骤）

大多数用户跳过这步，导致Hermes表现像个普通聊天机器人。正确做法是花5分钟提供背景信息：

在首次对话中发送：
```
我是[职业/角色]，主要工作涉及[领域1]、[领域2]。
习惯使用[编程语言/工具偏好]。
对[主题A]、[主题B]特别感兴趣。
正在进行的项目：[项目名称]，目标是[具体目标]。
```

Hermes会将这段信息写入长期记忆，后续所有对话都基于此背景展开。

## 操作清单：验证Hermes是否真正"记住"了

完成配置后，按以下清单逐项验证：

- [ ] **记忆验证**：一周后询问"我上周在研究什么？"——应得到准确回答
- [ ] **跨平台验证**：在Telegram中记录一个想法，切换到Slack中询问同样的内容——应出现上下文连续
- [ ] **技能安装验证**：运行 `hermes skill install research-paper-summarizer` 并测试功能
- [ ] **模型切换验证**：切换底层模型后，询问一个记忆中的项目——记忆应保持不变（记忆存储在网关层，独立于模型）

## 核心功能实战

### 持久化记忆的实际效果

**场景**：周一在Slack中讨论了一个技术方案，生成了三个候选方案A/B/C。

**周五**在CLI中询问："那个技术方案最后选了哪个？"

Hermes的回答应包含：
- 周一讨论的三个方案
- 周二倾向的方案B的修正版本
- 周三最终决策的理由

如果做不到这一点，说明记忆功能未正确激活。

### 技能（Skills）体系

社区已有200+技能，覆盖研究、内容创作、DevOps等领域。安装方法：

```bash
hermes skill install research-paper-summarizer
hermes skill install code-review-helper
hermes skill install knowledge-graph-visualizer
```

每个技能都是独立的模块，安装后可通过斜杠命令调用，例如 `/research-paper-summarizer [论文链接]`。

### 定期提醒（Nudges）配置

Hermes支持基于记忆的主动提醒。典型配置：

```
每周五晚上20:00，提醒回顾本周与AI工具相关的对话，并生成要点总结。
```

配置后，Hermes会在指定时间主动推送回顾内容，并附上可执行的下一步建议。

## 常见问题排查

| 问题 | 可能原因 | 解决方案 |
|------|---------|---------|
| 记忆不持久 | 网关未正常运行 | 检查 `hermes gateway status` |
| 切换模型后记忆消失 | 误以为记忆在模型层 | 记忆在网关层，重启网关即可恢复 |
| 平台消息不同步 | 网关未连接该平台 | 检查各平台Bot Token配置 |
| 技能安装失败 | 网络或权限问题 | 检查npm权限和网关日志 |

## 记忆锚点

**反常识结论**：Hermes Agent安装完成后，真正产生价值的不是"它能做什么"，而是"它记住了什么"。60%的用户在配置完成后，因为忽略了记忆初始化步骤，始终把它当普通聊天机器人使用。正确的初始化，决定了它是"一次性工具"还是"长期伙伴"。
