> **热点手记** · AI 工具测评 · hot.snaplinediary.cn · 估读约 3 分钟 · 2026-05-20

## 坑 1：追新模型忽略任务

**现象**：每个发布会换默认模型。  
**代价**：稳定性下降，提示词失效。  
**对策**：生产用「够用」模型，实验用新模型分支。

## 坑 2：上下文超限

**现象**：整库粘贴，中途失忆。  
**对策**：`.cursorignore` / 分会话；大改用 Plan + 分目录。

## 坑 3：无知识沉淀

**现象**：聊完即散。  
**对策**：[KB] 标记 + 周复盘（见 Hermes 知识库文）。

## 坑 4：迷信全自动

**现象**：Agent 直接 push main。  
**对策**：分支保护 + Hooks + 必审 PR。

## 坑 5：工具孤岛

**现象**：五个 App 五个上下文。  
**对策**：栈内只保留两层（通用 + 编码）。

## 坑 6：隐私误判

**现象**：把客户数据贴进免费 Chat。  
**对策**：企业协议、本地 Agent、脱敏样本。

## 坑 7：只看功能列表

**现象**：购买前未跑标准任务。  
**对策**：30 分钟试用同一 bugfix。

## 坑 8：无使用边界

**现象**：整天调教 prompt 不写码。  
**对策**：番茄钟：25 分钟产出 + 5 分钟 AI。

## 坑 9：账单失控

**现象**：API 超额。  
**对策**：预算告警、小模型默认。

## 坑 10：不复盘

**现象**：重复订又退同一工具。  
**对策**：每月记「留/删」原因一行。

## 避坑检查表（发布前自检）

- [ ] 标准任务测过  
- [ ] 订阅数 ≤ 3  
- [ ] 敏感数据政策读过  
- [ ] 自动续费日历  
- [ ] 大改走 PR

## 事故复盘模板

```

对策：加 PreToolUse / 改流程
负责人：
复盘日：
```

十次小事故不如一次写进 wiki，团队记忆比 Chat 记忆靠谱。

## 保险与责任

工具条款多免责。关键系统仍要人工 sign-off。避坑文不能替代治理，只能降低概率。

## 十条避坑的可执行检查

1. 密钥是否进过 prompt 日志  
2. Agent 是否改过 `main` 无 PR  
3. 是否同时两个 Agent 改一分支  
4. MCP 是否默认写库  
5. 月费是否无 API 上限告警  
6. 是否无备份就升级网关  
7. 是否把客户 PII 贴进个人 Bot  
8. 是否无 Plan 直接跨目录改  
9. 是否把 benchmark 当生产承诺  
10. 是否无 on-call 就上 OpenHands  

每条对应一个 **本周** 能完成的修复动作，不要写成永久口号。

## 预算护栏

为每个 Agent 账号设月度 API 硬上限；为团队设「自主 merge」白名单路径。超出上限时自动降级到小模型或只读模式，而不是月底账单惊吓。

## 安全演练（季度一次）

故意在 prompt 里粘贴假 AWS Key，看工具是否拦截或告警。故意让 Agent 改 `main`，看 Hooks 是否拒绝。故意给恶意 issue 链接，看 OpenHands 沙箱是否隔离。演练要写下来，不是口头「应该没问题」。

## 与法务的协作句

「我们使用云端 Agent 处理脱敏后的代码片段，完整仓库不出境；日志保留 X 天；用户可删除记忆。」把这句放进 DPA 附录，比事后补洞快。

## 事故后的 Retro 五问

发生了什么？哪条避坑检查可拦截？Hooks 是否缺失？谁批准了权限？下季度演练是否覆盖？写进团队 Retro 模板，比口头「下次注意」有效。

## 实操附录：避坑演练日

选非高峰一天，四组分别演练：密钥泄露、Agent 改 main、MCP 写库、月费爆表。每组 45 分钟，输出「哪条检查可拦截」与「补丁 PR 链接」。演练结束把 Hooks 样例与预算告警接入正式仓库。没有补丁的演练等于团建，不算安全建设。

## 读者可执行检查

勾选本文十条避坑中你团队已覆盖的项，未覆盖的项指定 owner 与截止日期。十条全空则暂停新 Agent 采购。

## 发布前核对

十条避坑逐条勾选 owner。无 owner 的条目标红，下周站会第一条讨论，不得淹没在「AI 很热」里。

## 会后跟进

演练补丁 PR 合并后，在站会白板贴「已拦截类事故」计数，季度归零为目标。

## 版本记录

演练补丁合并后，在团队 retro 模板增加「AI 避坑」固定一格，避免只有本文读者知道十条检查。安全同事每季抽一条演练，保持肌肉记忆。

避坑不能消除模型幻觉，只能降概率。高度监管行业清单更长，需法务模板。若你几乎不用 AI，本文可跳过。对策随产品变，执行时对照官方安全白皮书。
