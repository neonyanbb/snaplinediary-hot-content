# snaplinediary-hot-content

**当前状态**：仓库已精简为 **单页静态测试**，用于验证 GitHub → Cloudflare Pages 链路；不含正文稿件与广告配置，降低误提交敏感信息的风险。

| 项目 | 说明 |
|------|------|
| 页面源文件 | `public/index.html` |
| 构建命令 | `npm run build` |
| 输出目录 | `_site/`（与 Cloudflare Pages 配置一致） |

恢复 Eleventy / 多文章结构时，再在单独分支或备份中合并，勿在本测试分支混入未审核正文。

本地预览（可选）：

```bash
npm run serve
```
